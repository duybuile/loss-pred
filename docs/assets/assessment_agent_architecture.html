Assessment Agent Architecture

Model-first reviewer support with fallback-only retrieval and deterministic escalation.

Input Record

Incoming risk submission

  • risk_type, territory, industry
  • limit, premium, prior_claims
  • years_trading, broker

Predict Loss

Primary evidence tool

  • probability_of_loss
  • top_features
  • input_quality_flags
  • model_warnings

Hybrid Controller

Deterministic policy engine

  • Compute confidence from |pl - 0.5|
  • Downgrade for missing or invalid inputs
  • Trigger retrieval only for low confidence
  • Escalate if evidence conflicts

Fallback Retrieval

Historical analogs on demand

  • Run once for weak model evidence
  • Use small n_results
  • Summarize support or tension
  • Never search for certainty

Reviewer Response

Actionable assessment output

  • recommendation
  • risk_assessment
  • confidence_level
  • review_guidance

Confidence Policy

  • High: margin >= 0.30
  • Medium: 0.15 to 0.29
  • Low: margin < 0.15
  • Missing fields or warnings force low

Guardrails

  • Bound retrieval to one round
  • No repeated tool loops
  • Escalate when model and retrieval disagree
  • Use LLM only for coherent summaries

Human Review

Triggered on weak or contradictory evidence

  • low confidence after retrieval
  • model and retrieval conflict
  • critical model warning or invalid input
Output Contract recommendation, risk_assessment, confidence_level, key_factors, similar_records_summary, second_opinion_recommended, review_guidance, tools_used, warnings
pl = probability_of_loss | confidence is computed in the controller, not in predict_loss
